Card AD-141: an opt-in price table so the usage report can say what the reported tokens would cost at the person's own prices.

## What changed

- `agentd.toml` `[usage]` accepts an optional `[[usage.price]]` array of tables: `model` (a name or a simple glob, `*` and `?`, compared without case), optional `provider` (compared without case; left out, the entry prices any provider — transcripts of some tools name none), and `input`, `cache_read`, `cache_write`, `output` in US dollars per million tokens. No prices are shipped. Each entry is checked (`UsageConfig::check` → `price_table`): a missing, negative or non-numeric number, an empty model, an unknown field or more than 256 entries is a configuration error named by its index and field. Like the rest of the file it does not stop the daemon: the usage worker logs it once (and once more when it holds again) and `usage` queries answer `invalid` with it.
- Core gains `usage::price` (the `Table`, the glob, and `Costing`, the fold of a row's buckets into a `CostReport` in whole microdollars) and `Row.cost`, present only where a price matched some of the row's usage. The uncached share of the inclusive input total (less the cache reads and writes reported) is priced at `input`, cache reads and writes at their prices, output at `output`; reasoning is inside output and not priced again. Coverage follows the counts' rules: complete only when every priced counter was reported by every sample and collection is caught up; partial when some did not say or some of the row's buckets matched no price; unknown (`—`) when nothing priced was reported. `Row::settle_coverage` / `demote_complete` replace the two hand-written coverage loops in the daemon and the standalone scan, so the cost follows its counts there too.
- The store's `usage_report` takes the table and prices each bucket by its provider and model while grouping, so the column is right for every grouping (by agent, model, provider, project, hour).
- `agentdocker usage` adds an `EST. COST` column, and a note under the table, only when some row has a cost; the MCP `usage` tool's rows carry `cost` only then (the field is skipped otherwise) and its description says what it is. The Usage screen adds an *Est. cost* column (wide table and narrow cards) only when some row has one; every cost's tooltip and accessible value say *Your price table in agentd.toml applied to the tokens reported; not a bill* after what its mark means.
- Docs: ARCHITECTURE (configuration, what is computed, coverage, the response schema, and that it is not a bill), GUIDE (the config example and the command table), DESKTOP-UX (the column), ICED-DESIGN (node ids).
- Tests: the pricing fold in core (matching and glob, first match wins, no match, coverage marks, zero prices, overflow), the configuration (missing/negative/non-number/empty model/unknown field/too many), the store fold (a priced and an unpriced bucket in the same row and apart, no table), the CLI cell, and the screen (no column without a price; the column, the dash and the tooltip with one).

## How to try it

```toml
[usage]
enabled = true

[[usage.price]]
model = "fable-*"
input = 3.0
cache_read = 0.3
cache_write = 3.75
output = 15.0
```

`agentdocker usage --by model` shows `EST. COST` with a value on rows whose model matches and `—` on the rest; without a matching entry the column is absent. `agentdocker usage --json` carries `cost` on the matching rows only. Set `output = -1` and the next query answers `invalid` with `usage.price[0] (fable-*) output must be US dollars per million tokens, zero or more`; the daemon keeps running.

## What it will not do

- It is an estimate from reported tokens at prices the person wrote; it knows nothing of a provider's actual rates, plans, discounts or minimums, and it is never added to any token total. It is not a bill.
- Nothing is fetched from any network; no prices ship with AgentDocker.
- The standalone `usage-scan` reads no `agentd.toml` and prices nothing.
- A row whose counters do not say which tokens were cached is priced as if uncached at `input`, and its cost is marked partial.

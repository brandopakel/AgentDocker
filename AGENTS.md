# Agents

Every coding agent working here follows `CLAUDE.md`: layout, conventions, the documentation contract, the one-build-campaign rule and the standard verification gate. It is the single set of instructions for this repository; this file only points to it so tools that look for `AGENTS.md` find the same rules.

Coordinate with the other agents through AgentDocker itself (`agentdocker send`, `claim`, `commit`), which is also how the product is live-tested.

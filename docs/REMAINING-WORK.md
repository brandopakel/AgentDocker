# Remaining engineering and release work

This is the active backlog for the `0.2.0-beta.2` source candidate. Source,
installation and acceptance are separate: use `agentdocker desktop status` and
`agentdocker daemon status` to identify what a machine actually runs. A newer
commit does not turn an older trial into evidence for different binaries.
Detailed trial pins remain in [the verification index](verification/INDEX.md)
and linked PRs; this file keeps current obligations and unresolved failures.

**The rollout is not complete.** The user requires macOS, Linux and native
Windows. A labeled portable Windows preview can collect feedback while its
installer and service are unfinished; it does not fulfill the full Windows
requirement. Stable macOS distribution also requires credentials and independent
hardware acceptance that are not available yet.

# Remaining engineering and release work

This is the active backlog. Detailed attempts, exact source/cleanup proofs and
raw failure locations live in [the verification index](verification/INDEX.md).
A later pass does not erase a failed run or prove its cause.

Published **0.2.0-beta.12** is reviewed source `d48c0ab6` (#330).
All 31 hosted assets, nine archives, five manifests and both preview feeds passed
verification. Mac ARM64, Oracle Ubuntu x86_64 and Windows x64 passed bounded
beta.11→12 install/update/rollback/reapply and service checks. Stable v0.1.0 and
Homebrew remain unchanged. Ledger 15/schema 27 is unchanged; beta.9/schema 26
cannot replace it over acknowledged delivery state.

**Full stable release remains incomplete.** Fresh-account, independent-hardware,
physical-input/accessibility, sleep/reboot and Developer ID/notarization gates
remain open. Native Codex, managed secret input and live daemon replacement stay
experimental. Current existing-account evidence is scoped in the tables;
synthetic providers and CI do not establish physical or fresh-login acceptance.

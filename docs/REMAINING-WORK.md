# Remaining engineering and release work

This is the active backlog, not a record of every attempt. Exact source commits,
failed trials, subsequent corrections and raw evidence locations remain in
[the verification index](verification/INDEX.md) and linked PRs. Source,
publication and installed acceptance are separate: use `agentdocker desktop
status` and `agentdocker daemon status` to identify what a machine runs.

Published `0.2.0-beta.8` is reviewed, integrated source `590c4bb9`. Its 31 hosted
assets, nine archives, five manifests and both preview feeds passed verification.
Actual beta.7 → beta.8 installation/update and schema rollback refusal passed
on Mac ARM64, Oracle Ubuntu and a Windows x64 runner. Hosted terminal/graphical
and installed-service checks passed in the private scopes indexed below.
Stable `v0.1.0` and Homebrew remain unchanged from the prepublication snapshot.

Source version `0.2.0-beta.9` is the next unpublished candidate. It includes
Claude reconnect preservation, native first-history recovery and receiver
lookup diagnostics. Candidate validation, review, publication and hosted
update/rollback acceptance are still required; beta.8 remains the download.

Beta.8 adds owned-thread idle MCP form/URL review and a 60-second Windows
service-management script allowance. Ledger 14/state schema 26 prevents binary
rollback to beta.7's schema 25 while preserving the installation. Never restore
an older delivery ledger over acknowledged input; an older-version trial needs
isolated state. The original Windows startup failures remain unexplained.

**The rollout is incomplete.** Native Codex launch and live daemon replacement
remain experimental. Preview distribution does not establish stable signing,
independent hardware, fresh accounts or physical accessibility. The installed
Oracle accounting preflight passed; its 48-hour trial is running, not accepted.

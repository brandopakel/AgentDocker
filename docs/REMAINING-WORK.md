# Remaining engineering and release work

This is the active backlog, not a record of every attempt. Exact source commits,
failed trials, subsequent corrections and raw evidence locations remain in
[the verification index](verification/INDEX.md) and linked PRs. Source,
publication and installed acceptance are separate: use `agentdocker desktop
status` and `agentdocker daemon status` to identify what a machine runs.

Published `0.2.0-beta.5` is reviewed source `fc54edc9`. Its 31 hosted assets,
nine archives and five manifests passed integrity checks; explicit installation
and beta.4 → beta.5 update, rollback and reapplication passed on Mac ARM64 and
Oracle Ubuntu x86_64. Stable `v0.1.0` and Homebrew remain separate.

The protected-tag publication includes reviewed Windows installation and connector
services, accounting attribution and growing-source recovery. Native Codex #256
remains a separate change excluded from this release. Hosted Windows passed
12 installation/feed/uninstall, 13 installed daemon and 24 installed connector
checks. Mac and Oracle hosted startup, terminal and graphical draft/reopen checks
passed with synthetic providers. The corrected Linux fixture driver and the two
Windows driver failures remain recorded; a two-release Windows installed update/
rollback trial still needs a second compatible release.

**The rollout is incomplete.** Full macOS, Linux and native Windows support
requires the engineering and acceptance gates below. Preview distribution does
not establish stable signing, a fresh account or physical accessibility.
